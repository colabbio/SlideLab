# Changelog

## [2.1.0] - 2026-08-17

- **MedVFS & SlideLab Integration**: Full support for zero-copy streaming WSI tile extraction directly from MedVFS virtual mount paths.
- **Macenko & Vahadane Stain Normalization**: High-speed batch stain normalizer with GPU tensor acceleration.
- **HDF5 Feature Embeddings**: Unified export schema for patch embeddings compatible with PyTorch ABMIL pipelines.

## [2.0.0] - 2026-07-20

- Multi-resolution tissue segmentation and pyramid patch generator.

## [1.0.0] - 2026-07-10

- Initial stable WSI preprocessing engine.

## [0.1.0] - 2026-07-05

- Initial release.
